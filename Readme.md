# Python Menu-Driven Calculator

## About the Project
This is a simple menu-driven calculator program written in Python. It allows users to perform basic arithmetic operations using a function with an argument.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User input for numbers and operation selection
- Division-by-zero error handling
- Function with an argument

## Technologies Used
- Python 3

## Menu Options
1. Perform addition
2. Perform subtraction
3. Perform multiplication
4. Perform division

## How to Run

**Step 1:** Install Python 3 from [python.org](https://www.python.org/downloads/) if it is not already installed.

**Step 2:** Clone this repository:

```bash
git clone https://github.com/IzhaanTech123/python-calculator.git
```

**Step 3:** Open the project folder:

```bash
cd python-calculator
```

**Step 4:** Run the Python program:

```bash
python calculator.py
```

On some systems, use `python3 calculator.py` instead.

## Example Output
